# 📚 BookBuddy

BookBuddy is a simple and responsive book browsing website built using **HTML** and **CSS**. It was developed as an early frontend project to practice webpage layout, responsive design, and styling concepts.

---

## 🚀 Features

- Responsive homepage design
- Book categories including:
  - Self Help
  - Non-Fiction
  - Fiction
  - Crime
- Search bar UI
- Book cards with images and prices
- "Add to Cart" button interface
- Contact section and footer

---

## 📖 Learning Outcomes

This project helped me practice:

- HTML page structuring
- CSS styling and layouts
- Flexbox
- Responsive UI design
- Organizing frontend components
